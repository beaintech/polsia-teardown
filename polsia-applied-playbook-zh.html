Polsia 实战：对我们意味着什么

第一部分问：这个工具对我们值不值 20 美元，如果值，该怎么用。第二部分问：如果我们也做一个类似的东西，我们要改什么。

配套文件：第一份 Polsia 分析简报（什么是 Polsia、怎么赚钱、为什么融了 3000 万）。本文以图为主，每节先看图再解释；全部图形内联矢量，离线可用、打印干净。

「该不该付那 20 美元」的一句话答案

不该把它当运营生意的地方。该把它当一次性弹药去测二十个想法——但前提是：它永远不碰我们的名字、我们的客户、我们的代码。

第一部分 · 我们的生意

对我们值不值 20 美元，该怎么用

诚实地回答下面三个问题，决策自己就出来了。

为什么「否」才是我们主营业务的诚实答案

agent 层我们本来就有。 编排是商品化的东西——OpenClaw 有 37.5 万 GitHub 星，本周刚发了一个 933 位贡献者的版本。那是 Polsia 建的部分，也正是我们要租的部分。

为一件我们自己能托管的事付 20% 抽成。 对一个会写代码的团队来说，这是整个市场里性价比最差的档位。抽成是给不会写代码的人定的价。

它的短板正是我们的长板。 它有记录在案的失败是先建后验。判断力和验证恰恰是我们擅长的部分。租一个跳过我们最强步骤的工具，是反的。

那 20 美元到底是买什么的？

不是买一个生意。是买二十次低价探针——找出哪个想法真有信号，然后把那一个拿回来、在我们的技术栈上好好重做。

值得用它做的

  • 想法霰弹枪。 20 个想法 × 20 美元，跑 30 天，留下有反馈的那个。市场上没有别的东西让这件事这么便宜。
  • 逆向研究。 20 美元买一个 agent 编排、跨公司记忆、多线变现的可用参考实现。便宜的研究。
  • 在陌生市场试需求。 想不知道某个垂直有没有人要，用一次性品牌去试，不花钱也不担风险。

永远别用它做的

  • 别指向我们现有的品牌。 agent 会以给它的名字发冷邮件、公开发帖。标错价格、编造说法的记录都摆在那里。
  • 别把想留下的东西放上去。 代码和域名在 Polsia 的基础设施上，用户反映取不回来。
  • 别把「已完成」当完成。 有记录：47 个任务里 21.3% 真成了。任何输出都要自己再验证一遍才信。
第二部分 · 如果我们来做

我们要改什么，哪里还是空档

下面是 Polsia 的流程（左）和我们设想的流程（右）。绿色框是改动——四处新增，外加重写收费模型。

最关键的一处：验证闸门

Polsia 的核心设计缺陷不是建得烂，而是在任何人要求任何东西之前就开始建。如果我们只改一处，就是这里。

第二处：用阶梯替代开关

Polsia 的自主是二元的——要么全自动，要么全手动。这对任何真实生意都是错的。下面是我们会交付的阶梯，默认第 2 级。

哪些其实是空档，哪些已经被人占了

我查了竞品已经占了哪些位置，免得我们花几个月做 Lindy 去年就交付的东西。这张表是诚实的版本。

我们的想法现状谁已经有了
花钱前先验证完全空档没有任何在售产品做这个。我们最强的位置。
代码归用户、自带云本品类内空档n8n 和 OpenClaw 在工作流自动化里做，但没有业务运营平台做。
验证层作为定位空档作为工程模式已被验证：LangChain 靠 harness 改动从 52.8% 提到 66.5%，没换模型。
自主阶梯部分被占Lindy 对任何对外影响设审批；Agentforce 按 agent 设边界。没人做编号阶梯。
人工审批队列已被占Lindy，以及 n8n 的人工介入节点。是入场券，不是差异化。
封顶混合定价主流，不是差异化Intercom Fin 每条解决 $0.99、Zendesk $1.50、HubSpot $0.50。仍是对 Polsia 20% 的重大改进。

对我们自己计划的一处修正

我原本以为应该用纯结果定价取代抽成。数据说不。Bain 调研的 30+ 家厂商里，65% 用混合定价，纯结果定价一家都没有——纯结果定价在 agent 干成了、客户却仍不愿付钱时，会白白漏掉太多收入。

所以正确模型是固定订阅 + 点数 + 一段结果分成：超过收入阈值才启动、并且封顶。它保留了 Polsia 声称的对齐故事，却没有客户恨透的永久 20%。

先做哪个，先跳过哪个

v1 就做

  • 带两道检查的验证闸门。这就是产品。
  • 自带 GitHub 和云。我们建起来便宜，而且是这个品类里竞品没有的。
  • 默认第 2 级自主 + 审批队列。
  • 一个真跑检查的验证器——HTTP 200、部署成功、邮件送达——否则拒绝标记「已完成」。

刻意跳过

  • 市场和基金路线图。 Polsia 的 PPT 写「不是工具，是经济体」。那是 B 轮故事，不是 v1。
  • 大规模跨公司记忆。 它是 Polsia 唯一的真护城河，但要有几千家公司才有意义。
  • 广告管理。 Meta 和 Google 广告自动化是合规与客服的雷区，让给别人做。
  • 不做通用。 只选一个垂直——独立开发者和顾问，是我们真正懂的那个。

诚实的总结

Polsia 证明了品类和需求是真的。它也证明了需求和满意度是两回事——同一个融了 3000 万美元的产品，94% 弃用、1.8 分。

它没做的，正是能修复这一切的那个东西：在开工之前先问有没有人想要它。 这是图里的一个框，没有任何人建过，也是「卖忙碌」和「卖结果」之间的区别。
